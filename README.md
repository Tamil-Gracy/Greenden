# 🌿 GreenDen - Plant Nursery Website

A modern, responsive multi-page plant nursery website built using **HTML** and **Tailwind CSS**. GreenDen provides a clean and user-friendly interface for exploring indoor plants, learning about the company, browsing products, and contacting the nursery.

## 🚀 Features

* 🏠 Responsive Home page
* 🌱 About Us page
* 🪴 Products page with plant listings
* 📞 Contact page
* 📱 Mobile-friendly design
* 🎨 Modern UI built with Tailwind CSS
* ⚡ Clean and reusable code structure
* 🌿 Attractive typography and layout

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Responsive Web Design
* CSS Flexbox
* CSS Grid
